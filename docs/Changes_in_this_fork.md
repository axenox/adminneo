## Accepted upstream

- **MS SQL `(max)` metadata and editing:** upstream commit [`6645bf09`](https://github.com/adminneo-org/adminneo/commit/6645bf09) fixes `varchar(max)`, `nvarchar(max)`, and `varbinary(max)`. Unlike the original fork implementation, it retains the base type and represents the length as `max`. The fork now uses that implementation, keeping only the dropdown extension described above.
- **Complete MS SQL view definitions:** upstream commit [`9cbecd5a`](https://github.com/adminneo-org/adminneo/commit/9cbecd5a) incorporates the full-definition fix and quotes schema and view identifiers separately before resolving `OBJECT_ID()`. The former fork implementation has been replaced entirely by upstream's version.

## Upstream synchronization

The current integration uses `origin/unchanged` at [`a4fe19b3`](https://github.com/axenox/adminneo/commit/a4fe19b3), including AdminNeo 5.9.0 and the following development-version bump. Integration commit: TDB.

Conflicting implementations were resolved as follows:

- **MS SQL result handling and transactions:** retain upstream's later-result error reporting and native SQLSRV/PDO_DBLIB transaction fixes, alongside fork statistics-message collection. PostgreSQL and MS SQL retain the new `transaction_ddl` capability as well as fork copy, routine, and statistics capabilities.
- **MS SQL `(max)` values:** retain upstream's canonical metadata and length parser; adapt only dropdown presentation and submission as described above.
- **MS SQL views:** use upstream's quoted, schema-qualified `OBJECT_DEFINITION()` query without a parallel fork version.
- **MySQL search and statistics:** retain upstream's bit-column search validation and fork runtime statistics; these are independent methods inserted at the same location.
- **Table structure actions:** retain upstream's clipboard export and format selector alongside the fork's table-copy action. Clipboard copying and database table copying remain separate commands.
- **Changelog and translations:** retain the upstream release heading and Tamil text corrections, keep fork statistics translations, and remove the duplicated fork claim for the now-upstream `(max)` fix.
